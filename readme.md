# Visualisers for Machine Learning Concepts
This repository contains interactive visualizations designed to help users understand key machine learning concepts. Each visualization is built using HTML, CSS, and JavaScript, and can be accessed directly through a web browser.
## Local Setup
1. Clone the repository:
   ```bash
   git clone
    ```
2. Navigate to the project directory:
    ```bash
    cd Visualisation
     ```
3. Open `index.html` in your web browser to explore the visualizations.
